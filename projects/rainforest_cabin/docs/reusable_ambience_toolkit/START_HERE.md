# Start a new ambience project

1. Attach **AMBIENCE_VIDEO_MASTER_PLAYBOOK.md** to a new chat. That one file is
   self-contained. Add your reference image/video and describe your concept.
2. Paste the starter prompt from section 1, or use NEW_CHAT_STARTER.md. Fill the
   important unknowns in templates/PROJECT_BRIEF.md and project_config.json as
   the conversation settles them. Do not assume a previous chat's files persist.
3. Begin at references and composition, then work through the reviewed still,
   motion, audio, endurance, masters, thumbnails, YouTube details and delivery.

## What this package contains

- A generic master MD with the complete end-to-end workflow and decision matrices.
- Nine newly authored optional skill modules, each containing a SKILL.md.
- Editable project, source, event, QA, thumbnail, Studio, status, delivery and
  handoff templates. Templates are blank examples, not proof that any work ran.
- Reusable thumbnail prompts and stage prompts.
- Package integrity/structure validation and SHA256 manifest.

## What it does not contain

No finished scene, production asset library, universal render scripts, running
worker, installed software, paid licenses, cloud credentials or YouTube upload.
Actual project code must be implemented/tested for the chosen scene and machine.
It does not install skills or tools merely because the ZIP is extracted.

## Optional skills

The skill modules can be attached as task instructions or installed through your
client's supported custom-skill process, if it has one. Do not guess an installation
directory. If the client does not support them, use the main MD alone.

Existing skills named `ambience-long-video-release` and
`cloud-environment-onboarding:setup` may be useful where actually available. They
are not bundled pre-installed apps. The latter is only for environment setup.

Every new chat should inspect its actual tools/capabilities and explain any missing
rendering, browsing, image generation, storage, local-execution or upload ability.
