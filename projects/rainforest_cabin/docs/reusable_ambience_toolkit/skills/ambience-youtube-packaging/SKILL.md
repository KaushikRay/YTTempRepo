# Ambience YouTube Packaging

## Inputs

Final version manifests, actual source register/credits, event timings, approved
thumbnails, channel facts, language/audience, ad preferences and publication scope.

## Workflow

1. Write three truthful title options per version, checked against current limits.
   Include duration and material dark-screen timing. No fake recorded location,
   camera-footage claim for generated scenes, medical guarantee or ad-free promise.
2. Create a complete description with natural scene/sound introduction, duration,
   scene/dark behavior, useful true chapters, cross-link placeholders, disclosure,
   complete used-source credits and relevant hashtags.
3. Derive chapters from final timing, not shortened tests. Do not invent events.
   Stable ambience may need no chapters. Check current chapter rules if used.
4. Supply bounded comma-separated tags and a focused pinned comment. Count title,
   description and tags, retaining room for final URLs. Preserve complete CC BY
   author/source/license/change information in each applicable description.
5. Fill every Studio decision: thumbnail/files, playlist, audience, age, paid
   promotion, realistic-synthetic disclosure, chapters/places, language/captions,
   location/date, license, embedding/remixing, category, comments, monetization,
   mid-rolls, cards/end screens, checks and visibility. Assess actual facts and
   available options; do not blindly assign a children's audience or language.
6. Recommend private upload, full-resolution processing and actual copyright
   review before release. Keep unresolved links/dates clear. Record IANA timezone
   for schedules. Publication/scheduling requires the user's authorization.

## Outputs and acceptance

Complete Studio worksheet and separate title/description/tags/comment/settings
files per version, with actual thumbnail links. No claim of upload, scheduling,
monetization or claim clearance without verified execution/results.
