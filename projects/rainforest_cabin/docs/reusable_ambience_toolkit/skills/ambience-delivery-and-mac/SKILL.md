# Ambience Delivery and Mac

## Inputs

Actual masters/QA, source rights, sizes/hashes, intended storage/access, hardware,
authorized sharing/publication scope and available connectors/network routes.

## Workflow

1. Choose a real route: supported attachment, authorized storage, draft release,
   checksummed parts, timeline rebuild kit or source-render kit. Explain what the
   route delivers. A cloud path or preview is not a full-master download.
2. Verify host/network/auth/size issues separately. Git access does not imply API
   or upload access. A saved environment draft may not activate it. Never print
   credentials, bypass policy or expose private assets to make delivery easier.
3. For parts, use exact ordered byte slices and bounded I/O. Verify every remote
   part and whole joined-file hash. Preserve the only master until transfer is
   verified. Explain temporary disk and login/expiry requirements.
4. For a Mac timeline kit, bundle approved visual units and licensed audio inputs
   or verified fetch instructions. Blender is unnecessary for assembly but is
   required for a true source render. Different encoders may produce different
   bytes; do not promise exact cloud-master checksums for a rebuild.
5. Use numbered quoted-path launchers, a shared stage runner, private dependencies,
   checksums, disk checks, status and logs. Detect OS/chip/tool support. Provide
   official installation instructions, not security-disabling workarounds.
6. Test package extraction, dependencies and a short build where possible. State
   Linux versus real-Mac coverage. The user must launch local jobs unless an
   authorized connected execution tool actually controls their machine.
7. Verify user-facing download bytes/hashes and content, not only HTTP 200. A
   login HTML page is not a valid MP4. Give a concise README and resume handoff.

## Outputs and acceptance

Working links or an explicit remaining blocker, manifests, verified package,
commands/log paths, prerequisites, measured estimate basis and actual local/
cloud execution state. No upload/publication is implied by file preparation.


See [the master playbook](../../AMBIENCE_VIDEO_MASTER_PLAYBOOK.md) for the complete workflow. Current user instructions and governing tool/system rules take precedence over these defaults.
