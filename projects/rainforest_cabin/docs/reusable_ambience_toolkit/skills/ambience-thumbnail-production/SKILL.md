# Ambience Thumbnail Production

## Inputs

Approved scene frame(s), actual final versions/durations/dark behavior, channel
style, supplied fonts/branding rights and available image tools.

## Workflow

1. Create actual files, not only design directions. Default to three distinct
   options per version: A wide scene/topic headline, B closer subject/minimal
   text, C alternative composition/message. Respect a different requested count.
2. Prefer actual frames for literal fidelity. When using generative cover edits,
   supply the approved scene reference and use the required image tool. Preserve
   provenance and inspect invented fine detail; do not label them untouched frames.
3. Keep the scene/subjects/weather truthful. No absent lightning, creatures,
   people or unrelated objects. No No Ads claim. State dark-screen timing exactly,
   such as DARK AFTER 1 H, rather than implying black from the beginning.
4. Use concise high-contrast type, safe margins and a clear focal subject. Keep
   important text away from the bottom-right platform duration overlay.
5. Export compatible 16:9 images, e.g. 1280×720 sRGB JPG under a conservative 2 MB;
   verify current platform limits. Read every generated word and version label.
6. Inspect all covers at full size and around 320 px width, beside the approved
   scene. Correct spelling, legibility, clipping and misleading changes.
7. Deliver individual A/B/C files per version, labeled comparison and small-size
   sheets, hashes/provenance manifest and a verified ZIP/download route.

## Outputs and acceptance

Three real reviewed images for every requested version. Recommend an initial
choice as editorial judgment, not a measured winner. Do not claim Test & Compare
was run or a CTR improvement was measured when no audience experiment exists.


See [the master playbook](references/AMBIENCE_VIDEO_MASTER_PLAYBOOK.md) for the complete workflow. Current user instructions and governing tool/system rules take precedence over these defaults.
